# data/ —— 示例数据目录

## ⚠️ 放数据前必读

这个目录**只允许放脱敏后的示例数据**。上传前请逐条确认：

| 检查项 | 说明 |
|---|---|
| 无真实客户名称 | 公司名、项目名一律替换为"XX公司""A项目" |
| 无个人信息 | 人名、手机号、身份证、工号全部删除或打码 |
| 无商业机密 | 报价、成本、未公开的参数、合同条款不要放 |
| 无内部资料 | 公司内部文档（非你个人成果）涉及知识产权问题 |

**判断标准**：这份材料如果被陌生人看到，会不会给你的客户或前公司造成影响？

## 建议放什么

| 文件 | 用途 |
|---|---|
| `sample_docs.md` | 一篇虚构的示例知识库文档，让别人能理解你的切片策略 |
| `slicing_demo.md` | 展示文档如何被切分成片段（这是 RAG 的核心环节） |

## 不建议放什么

- ❌ 原始 PDF / Word / Excel（`.gitignore` 已拦截）
- ❌ 完整知识库导出（体积大且敏感）
- ❌ 任何带真实业务信息的文件

## 为什么要放示例数据？

面试官看到仓库里有（脱敏的）示例数据，能快速理解你的项目在做什么。
一个只有文档没有数据的 RAG 项目，说服力会打折。
