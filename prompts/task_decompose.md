# 任务拆解 Prompt

## 用途

处理**复合型提问**（一句话里含多个约束）时使用。

健身场景中用户常把多个条件挤在一起，例如「我乳糖不耐受，还要增肌，每天只有 40 分钟」，
不拆解就容易只答其中一部分。

## 模板

```
用户问题：{user_query}

请按以下步骤处理：

第一步：列出问题中所有的约束条件（身体状况、饮食禁忌、时间、目标等）。

第二步：逐条检查方案是否满足每个约束：
- 约束 A（如乳糖不耐受）→ 饮食中排除乳制品
- 约束 B（如增肌）    → 热量盈余 + 蛋白质 1.6-2.2 g/kg
- 约束 C（如时间有限）→ 控制单次训练时长

第三步：输出方案，并逐条对应说明如何满足各约束。

注意：
- 不得遗漏任何一条约束
- 若某条约束涉及健康状况（疾病、孕期、用药），立即停止并转介医生
- 若约束之间冲突（如「增肌同时快速减脂」），指出冲突并给折中方案
```

## 示例

**输入**：我素食，又要减脂，每天只有 30 分钟，怎么练怎么吃？

**拆解**：
1. 素食 → 蛋白质来源限定为豆制品、豆类、蛋奶（若接受）、谷物组合
2. 减脂 → 热量缺口 300-500 kcal，蛋白质 1.6-2.2 g/kg
3. 时间 30 分钟 → 复合动作为主，力量与有氧组合

**输出**：
```
【饮食】素食蛋白来源：豆腐／毛豆／藜麦／豆类组合，每日约 __ kcal，
        蛋白质约 __ g（按体重 __ kg × 1.6 g/kg 计算）
【训练】30 分钟方案：热身 5 分钟 + 复合动作 20 分钟 + 拉伸 5 分钟
        周一／三／五执行，其余日快走
```

## 反例（要避免）

**输入**：我素食，又要减脂，每天只有 30 分钟，怎么练怎么吃？

**错误输出**：只给了减脂餐单，完全没有回应「素食」和「30 分钟」两个约束。

→ 这是复合问题最典型的失败模式：**只答了最显眼的那一个条件**。

## 效果记录

**待验证**：当前复合问题准确率 **50%**（4 条用例全部只答一半），
启用任务拆解后的评估目标为 **80% 以上**。
